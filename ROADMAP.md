# Roadmap

Status 2026-10-09: **P00 next** (install and verify on the owner's Windows machine). The product is built and tested locally far ahead of the plan; no measurement on a real pair yet, nothing deployed. Details: `memory-bank/progress.md`. Working plan with scope, human steps and declared spend per phase: `phases/` (order table in `phases/README.md`).

Phases run in order. A phase is done when its gate passes: `npm run hp -- gate P0x --product` re-verifies the phase's evidence records, runs `npm run verify` and closes the phase bead with a read-back (`HYPERPOWER.md`). The phase numbers changed on 2026-10-09 (D-048); `phases/README.md` maps the earlier P0 to P6.

| Phase | Goal | Exit criteria (all required) |
|---|---|---|
| **P00** Install and verify | The cloud-built system runs on the owner's Windows machine with every check and guard proven. | `npm run verify` and `npm run verify:e2e` green on Windows; J-01 to J-09 replayed into the evidence ledger; tools installed from the registry with SHA256; git and Cursor hooks proven through real invocations; Beads holds one bead per phase; doctor clean. |
| **P01** Measurement harness | Prove the QE + senate decision on one real language pair before selling anything. English to Serbian is the first measurement pair: a test instrument, not the target market. | Full pipeline runs end to end on real documents for the pair with real providers. A human-labelled reference set exists for the pair. Escaped-error rate on auto-approved segments is measured with a confidence interval and is at or below `escaped_error_target`, or the gap is understood and documented. Auto-approve rate and cost per word are measured. Evidence pack (JSON + PDF) generated for every job. |
| **P02** Staging deploy | The system runs on one EU Hetzner host the way production will. | Compose deploy behind Caddy with TLS, migrations on start, automatic deploy from `main` through a restricted key, deployed commit equals HEAD, J-01 to J-03 green against the public URL, nightly encrypted off-site backups, restore drill done once, error tracking and uptime monitoring on. |
| **P03** Money and legal readiness | Money moves for real in both directions and the documents a launch needs are reviewed. | Payments integrated. Real payout provider sends payouts. Payout runs and payments reconcile with the ledger to the cent. Tax review of the invoice rule (D-029) done. Legal review before public launch completed (terms, DPA, subprocessor list, privacy policy, reviewer contractor terms). Security pass done (tenancy, rate limits, upload limits, dependency audit). |
| **P04** Self-serve launch | A paying customer can sign up, upload, get a quote, pick a tier, pay and download the result without the operator, and human review capacity no longer limits the tiers sold. | Register, quote, project, delivery, invoice work in production for the supported formats. Tiers and regulated-vertical rules enforced in the API. At least 3 target languages calibrated with the P01 method. Webhooks, API keys, usage and invoices live. Reviewer onboarding, qualification tests, task routing, per-decision pay, disputes and payouts run without manual steps; reviewer quality scores and levels drive routing. Median wait for a review task within the target agreed for `hybrid` in the supported pairs. Error tracking and uptime monitoring on production. |
| **P05** Integrations | Content flows in and out without manual upload. | GitHub connector (repo files to jobs, PR back). Figma connector. At least one headless CMS connector. Connectors use the public API and webhooks only. Each connector has an end-to-end test against a sandbox. |
| **P06** More formats via Okapi | Long-tail file formats. | Okapi Framework sidecar running behind `FormatHandler`. IDML, DITA and at least three more formats round-trip in tests. Python handlers and Okapi produce the same tagged text for overlapping formats or the difference is documented. |
| **P07** Enterprise | Sell to companies with procurement checklists. | SAML/OIDC SSO, SCIM or equivalent user provisioning, audit log export, data retention controls per org. SOC 2 Type I report (Type II window started). Penetration test done and findings closed. |
| **P08** White-label for agencies | Language service providers run their own branded instance on Arbiter. | Custom domain and branding per tenant, sub-tenants (agency to its clients), agency-owned reviewer pools, agency pricing and invoicing to their clients, data isolation verified by test. |

Rules:
- No phase claims a metric that was not measured. No customer names or revenue in this file.
- Anything moved between phases is a `docs/decisions.md` entry.
